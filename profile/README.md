# MatchDay-Planner ⚽

> 웹소켓 기반 실시간 축구 경기 기록·중계 서비스  
> 🌐 **[matchday-planner.com](https://matchday-planner.com)**

---

## 📌 프로젝트 개요

### 왜 만들었나요?
아마추어 축구 대회는 경기 결과를 실시간으로 공유하거나 기록을 체계적으로 관리할 수 있는 도구가 없었습니다.  
MatchDay-Planner는 **리그·토너먼트 관리부터 실시간 경기 중계까지** 하나의 플랫폼에서 처리할 수 있도록 설계된 스포츠 대회 관리 서비스입니다.

### 실제 사용 사례
> 🏆 **2026 동두천시장배 전국 대학동아리 축구대회**에 실제 투입되어 8개 팀의 경기를 기록·관리하였습니다.
